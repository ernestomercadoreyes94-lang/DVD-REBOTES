## ⚠️ Si sale "Windows protegió su PC" (SmartScreen)

Al abrir `DvdRebote.exe` o `dvd_config.exe` puede salir una ventana azul que dice
**"Windows protegió su PC"**.

**No es un virus.** Sale porque el programa es nuevo y no tiene firma digital
(las firmas cuestan dinero cada año). Windows muestra ese aviso con cualquier programa
que no conoce todavía.

Para abrirlo:

1. Haz clic en **Más información**.
2. Haz clic en **Ejecutar de todas formas**.

Solo tienes que hacerlo la primera vez.

Si lo descargaste desde el navegador y Windows lo bloquea, también puedes hacer
**clic derecho en el archivo → Propiedades → marcar "Desbloquear" → Aceptar**.
